# Northwind Park

CodeAlpha Full Stack Development — Task 2: Social Media Platform (MERN).

A small, family-safe social app: user profiles, posts and comments, likes and follows.
Seed content is clubs, books, coding, sports, and art. No dating, no DMs, no ads.

Full run instructions, seed logins, and the API table are documented in this README
as slices land on the `feat/task-2-social` branch.

## Quick start (development)

- Backend: `cd backend && cp .env.example .env && npm install && npm run seed && npm run dev`
- Frontend: `cd frontend && npm install && npm run dev`
- API health: `curl http://127.0.0.1:5001/api/health`
